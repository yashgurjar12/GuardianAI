## Rule 1: Update Project Memory After Every Task

Every time Antigravity finishes a task, the following memory files must be updated:

| Memory File | When to Update |
|---|---|
| `08-Development-Progress.md` | ✅ Always — after every task |
| `03-Database-Schema.md` | When data structures or mock data change |
| `04-API-Architecture.md` | When API-related patterns are added |
| `06-UI-Design-System.md` | When new components, colors, or design tokens are introduced |

This keeps context persistent across sessions.
